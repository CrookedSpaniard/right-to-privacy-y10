# Right to privacy · Year 10 Online Safety

A 30-minute games-based lesson for the British School Alzira · Xàtiva · Gandia Group.

- **Class mode** (teacher on the projector): hands-up counters, teacher notes, lesson clock and timers.
- **Solo mode** (students on their own devices): instructions on screen, answers saved automatically.
- Games: quick-fire recap, data trail, privacy circles, the four UK privacy laws + match-up, the Privacy Court, Data Inspector, Install SnapVibe, Design your society, Debate builder, bonus rights game, exit ticket.
- **My progress** copies a report with every answer for the teacher; a progress code moves work between devices. Nothing is sent to a server.

Plain HTML, CSS and JavaScript. Open `index.html` or serve the folder.
